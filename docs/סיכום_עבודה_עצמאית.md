הסתבר שהשלד כבר מתקדם יותר ממה שחשבתי. **80% מהתשתית כבר בנויה:**

**מה חסר:**

- ❌ Rollback
- ❌ **שכבת הזיכרון (הבידול)**
- ❌ UI דשבורד

### 2. **חקרתי לעומק את Anthropic Managed Agents**

מצאתי **הכל שאני צריך** כדי לבנות את הזיכרון. כתבתי קוד דוגמה (`docs/sample_agent_code.md`) שמראה איך זה ייראה בקוד אמיתי.

**גילוי חשוב:** ה-SDK של Anthropic ב-Python כבר תומך בזיכרון מובנה. אתה לא צריך לבנות כלום מאפס.

**מחירים מעודכנים:**
- Claude Sonnet 4.6: $3 input / $15 output לכל מיליון tokens
- חלון הקשר 1M tokens
- Cache hit = 10% מהמחיר (חסכון אדיר)
- Batch API = 50% הנחה

**חישוב מעודכן לפי המחיר האמיתי:**
- לקוח $89/חודש → עלות ~$5-8 לחודש
- Gross Margin = ~91%
